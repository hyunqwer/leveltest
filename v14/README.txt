      기존과 동일하게 유지하고, 내용(섹션명·눈금·총평)만 교체. 2p와 인쇄 하단은 v10 구성.

      ① 영역 완료 기준: 파닉스 5문항, 듣말·읽쓰·문법 8문항 이상. 기준 미만 영역은 미응시(시작점·원그래프·위치값·2p·3p·인쇄·추천교재 전부 미반영).
         현행 종료 로직(5문항)에서 기준값만 바뀜. 듣말이 8문항 미만이면 듣말·읽쓰 모두 미응시 → 파닉스만 응시한 리포트와 동일.
      ② 듣말 완료(8+) + 읽쓰 미완(8 미만·미응시)인 경우만 특별 처리: 듣말은 정상 반영(원그래프·2p 카드·3p), 읽쓰는 미응시이되 1p 원그래프에
         회색 "미완료" 링(v14GrayGauge, 점수·문항 수 없음)을 두고, 1p 원그래프 상자 아래 현행 #abnormal 박스에
         "듣기/말하기 읽기/쓰기 영역을 끝까지 풀지 않아 시작점에 반영되지 않았습니다. 정확한 진단을 위해 재시험을 권장합니다." 노출.
         시작점은 파닉스 기준(섹션명 "나에게 맞는 파닉스 학습 시작점"), 위치값은 LS+P 조합(시안은 예시값), 2p는 파닉스·듣말 카드 + 읽쓰 회색 카드(축만, 막대 없음, 가운데 "미완료", 아래 "내 수준" 줄은 비움) + 파닉스 처방 박스,
         듣말·읽쓰 처방 박스(두 카드 아래 2칸 폭)에는 같은 안내문을 볼드로만. 추천교재는 파닉스만. 인쇄용은 읽쓰 미응시 처리 그대로(안내 박스 없음).
         시작점을 낼 영역(파닉스·문법·듣말+읽쓰)이 없으면 리포트 미전송(종료 로직: "반영 영역 있으면 부분응답 출력, 없으면 미전송"). 샘플: e1_pl_inc / e4_pl_inc / ls_none.
         LS+G, P+G+LS 조합은 8문항 규칙에서 발생 불가(읽쓰 미완이면 시험 종료 → 문법 미도달).
      ③ 시작점 섹션명 3종: 듣말·읽쓰 둘 다 완료 → 나에게 맞는 학습 시작점 / 문법만·파닉스+문법 → 나에게 맞는 문법 학습 시작점 / 파닉스만(읽쓰 미완 포함) → 나에게 맞는 파닉스 학습 시작점. 배지는 BM별 단계값 그대로.
      ④ 문법만·파닉스+문법·파닉스만은 정상 응시로 보고 안내 없음. 파닉스만 응시 시 시작점은 배지만, 단계표 없음(현행과 동일, 파닉스 재검토 시 수정).
         인쇄용 시안은 초4 전 영역 1종만.
      ⑤ 샘플: e5_g(초5 문법만 실데이터), 불완전 케이스 2종은 실데이터 변형(읽쓰 값을 제거하고 inc='R'). 학년 평균 측정단계에 초5 추가(AVG_STAGE).

         학년→y값 초1 0.3 / 초2 0.6 / 초3 1.0 / 초4 1.5 / 초5 2.0 / 초6 3.0 / 중1 4.0 / 중2 5.0 / 중3 6.0 / 고1 7.0 / 고2 7.5 / 고3 8.0(yAxisLabelsNotP).
         현행은 정수 학년만 찍고, v14는 측정단계 소수점을 두 학년 사이에서 선형 보간. 파닉스 축 0~7(중고등 0~4).
      ⑦ 2p 처방 박스 폭을 상단 카드 묶음에 맞춤(3개: 25% 카드 3장+간격, 1~2개: 300px 카드), 가운데 정렬.

영역 조합별 처리
 - 시작점: 듣말·읽쓰 포함 → YES4.0 표 / 파닉스+문법 → 문법 기준(YES4.0 표, 코멘트 "○○ 단계 문법 영역 교재부터") /
   파닉스만 → 파닉스 단계표(초등 7칸, 중고등 4칸), 큐 없음. 총평 마지막 문장도 조합별.
 - 원그래프(300×260 상자 고정): 4개 2×2 / 3개 아랫줄 가운데 / 2개 상하 가운데 / 1개 상하좌우 가운데 (.v14gs flex).
 - 2p: 응시 영역 수만큼 카드(1~3개 모두 가운데 정렬, 시작점 태그 없음), 처방 박스는 P / 듣말·읽쓰 / G 중 해당 조합만.
 - 동단계 판정: 샘플 변환 시 듣말·읽쓰 YES4.0 칸이 같으면 tie (예시 학생 B 초1: 둘 다 Rookie 초2).
 - 인쇄용: 미응시 열은 현행처럼 빈칸 패턴 + "해당 영역에 응시하지 않았습니다." + 빈 색 박스 (PRINT_KEY=샘플키 로 검증 가능).
 - 학년 평균 측정단계(AVG_STAGE): 진단평가_응시데이터_추출_260928 동학년 응시자 평균(초1·초3·초4·초6·중1·고1), 파닉스는 최빈 단계. 실제 적용 시 전 학년 산출 필요.
 - 처방 문구는 모든 샘플에 동일한 현행 샘플(자리표시)을 넣었음(중·고등 샘플 문구 불일치는 자리표시 때문).
 - 중1 L+R+G 종합 위치는 B_LS+RW(문법 제외·임시) — LS+RW+G 조합 기준표 숙제.
