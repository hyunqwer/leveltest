[1p] 시작점 / 영역별 성취수준 / 동학년 대비 나의 위치
 - 상단: 시작점 배지 "Rising Star 초4" + 회색 큐 "읽기/쓰기 기준" + YES4.0 단계표(현행 구조, 2행).
 - 좌(340px): 원그래프 4개(현행 리포트 크기 118px). 듣말·읽쓰 응시 시 상단 듣기/말하기·읽기/쓰기, 하단 파닉스·문법 순.
   원 안 영역명+정답률 점수만. 태그는 "시작점 기준"(읽기/쓰기) 하나, 해당 원 바로 위에 붙임.
   강점/취약 태그·영역별 위치값·수준 표기는 1p에서 제거(AI 상담대본 모듈·교사용으로 이관).
 - 우: 벨커브(장식 곡선, x축 = 상위% 선형, 왼쪽 100% → 오른쪽 1%). 등급 라벨 없음.
   상단 구간 라벨은 현행 영어 표기 그대로 Below Average / Average / Above Average.
   눈금 90·80·50·20·10%, 3구간 옅은 배경(평균 이하 >80% / 평균 20~80% / 평균 이상 ≤20%).
   마커 "상위 42%"(종합, 버전B 4영역 합계 기준표). 80% 초과 시 "상위 80% 이하" + 마커 90% 고정.
   벨커브 아래 회색 캡션 없음(총평 문장에 "초4 응시자 중"으로 비교집단 표기).
   총평 2문장: "초4 응시자 중 상위 42%로, 평균 구간이에요. Rising Star 초4 단계 읽기/쓰기 영역 교재부터 학습을 시작하세요."

[2p] 영역별 진단 (3열: 파닉스 / 듣기·말하기+읽기·쓰기 / 문법)
 - 영역 블록: ① 수준 = 가로 사다리 막대(YES4.0 축 16칸, 파닉스는 7단계 축), 끝에 도달 단계명,
   막대 아래 ▲ "학년 평균 ○○" (실데이터 학년별 평균 SCALE → 단계 환산), 읽기/쓰기에 "시작점 기준" 태그
   ② 점수 굵게 + "k / n문항"  ③ 또래 = 영역별 동학년 위치 "상위 ○% · 구간"(80% 규칙 동일)
 - 하단 진단·처방 박스 3개(주황/초록/보라)는 현행 유지. 문구는 현행 샘플 자리표시.
 - 범례 "내 수준 / 학년 평균". 강점/취약 태그 없음.
